# 复跑与外部数据

从空目录克隆可直接离线执行 `runtime/decision.py` 和全部固定样例；参考推理只用标准库。样例账户和库存为合成数据。

完整历史回测及重新导出需要匹配起点、字段与版本的市场矩阵。历史大数据、实际库存和真实账户未放入仓库。`research/` 和 `frozen_reference/` 保留原源码及限制；使用 `NFB_REFERENCE_DATA` 指向经核验的数据目录。研究数据导入前核对数据自身清单，建立新的研究输出目录；保持正式模型文件原字节。

`evidence/ORIGINAL_FORMAL_155_HASHES.json` 保留原包155文件的哈希账本。交付有意省略旧站点更新工具和重复压缩包，本仓库文件清单另由 RELEASE_MANIFEST.json 定义。原验证与此次从独立目录复跑的检查分别存放，不能混写为实盘验收。
