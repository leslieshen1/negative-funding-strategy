# RC2：从输入状态生成JSON决策

日期：2026-11-08。策略标识 `nfb.strategy.20261108.rc2`；协议2.1.0。RC1保留，本次单独交付可运行的策略侧参考模块。

## 已完成的部分

此前RC1提供规则、Schema和消息校验。本次接上r7预计收入／成本计算与决策生成：读取账户、库存、行情、已结算费率及历史窗口，输出ENTER／ADD／REDUCE／EXIT／HOLD／RECONCILE、目标量、本次许可量、价格界限及划转意图。

执行方仍只需要收发JSON；下单、拆单、撤单、补腿及实际划转由原执行引擎负责。参考模块不需要联网，也不含交易所密钥。

r7是入场前的收入／成本过滤器。提前72小时转负、七天持续性等信号发现模型本轮没有重训或修改，原前瞻预测台账及删除的定时任务保持原状。

## 冻结计算口径

- 交易入场仍为最新已结算费率换算8小时后严格低于−0.1%，贴水至少0.3%；首笔不等T−1h，加仓不重复等待。
- r7训练样本保留原代码的严格低于−0.05%及贴水门槛，不能把交易入场门槛直接替换成训练门槛。按过去90天、已完成结局、每格至少200样本计算均值；优先联合分桶，不足时才回退资金费与基差两个边际估计。
- 收入样本仍使用原来的24小时退出确认、最长168小时结局定义；它与实际持仓的“原始24小时费率合计转正锁退”是不同层的定义。
- 成本保持原r7公式：0.30%往返预留＋四腿平方根冲击＋双腿往返价差。参考切片为 `min(3%×前24h较小成交额/24,10M)`，不是本次实际许可订单量。实际成交费用与冲击仍靠回执校准。
- 加仓另检查已有仓位影响后的有效费率；收入分桶本身使用原始市场费率，不把自身模型影响叠加到真实资金费现金流。
- 价格、成交量、OI、样本结局和模型发布时间均有时点检查。在线新增需要26条连续小时历史，缺关键数据时停止新增；现有退出锁及风险减仓不依赖r7必须可估计。

26条历史包含双腿收盘价、原币等价USDT OI、小时结束与实际接收时间。它们是原始市场数据，执行方不需要预测收入、成本或ADL。模型快照另附，不需要执行方自行训练。

## 两个原代码问题的处理

原r7的更新列表只写到2026年10月。本次导出14个更新节点，包括2026年11月1日；有效期到12月1日。没有对应月份的快照时不沿用旧月份开仓，仍可处理已有退出。导出器按输入数据覆盖日期生成月份，不再写死结束月份，且不覆盖已有模型文件。

原研究的第一个更新节点是2025年10月28日，不是10月1日。新校验器明确保留这个历史锚点；其他月份按月初截止，防止把真实的初始研究口径误判为前视。

## 资金与风险输出

最终目标和本次许可数量保持分离。多币共享组合预算与可用B资金；退出、减仓和新增共享各币的小时预算。A买回现金按最差允许买价加费用预留。

B→A用于买回、A→B用于1x保证金修复均只输出意图，到账前不能增加接收账户可用资金。发现1x保证金缺口时停止新增、标明资金修复或执行侧风险介入需求；不能把发出划转请求写成保证金已经恢复。

模块是无持久化副作用的计算函数。跨请求幂等、原子预留、撤单确认、退出锁持久化和回执去重仍需E01—E14内网验收。上游必须提供真实账户和合约映射，校验器不能证明这些声明是真实的。
