# 当前冻结策略

正式配置以 [MODEL_PROFILE.json](../runtime/MODEL_PROFILE.json) 为唯一机器口径。当前入场用已结算资金费换算为 8h 后严格低于 −0.1%，基差不高于 −0.3%；首笔不等结算前一小时。r7 收入/成本过滤器的训练门槛仍为 −0.05%，它与实际交易门槛不同。

| 规则 | 当前冻结值 |
|---|---|
| 初始资金及研究年化分母 | 10,000,000 USDT |
| 单币入场 / 市值目标上限 | 1,000,000 USDT |
| OI 上限 | 2.5% |
| 过去24h成交额上限 | 5% |
| 小时参与率上限 | 3%，只取前一完整小时可知量 |
| 收入与成本倍数 | 2 |
| 自身资金费影响 k | 4，冻结研究假设，尚无自身交易因果标定 |
| 退出 | 过去24h原始已结算资金费合计严格转正，锁退至义务清零 |
| B 保证金 | 配置1x，只认已到账可用资金 |

配置包含 VIP3 研究费率、价差和冲击模型。实际手续费必须从回执读取；当前成本校准截止2026-09-30。仓位限制是上限，不保证成交或完整退出。剩余永续、回购义务或未归还原币存在时，完整退出年化为 null。

闲置 U、生息保证金与原币用途研究在资金支持层单独表达，不静默扩大 RC2 的新增许可。详见 [原交接说明](RC2_ORIGINAL_HANDOFF.md) 与 [资金支持说明](../support/README.md)。
