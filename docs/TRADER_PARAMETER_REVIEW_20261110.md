## 可发群版本

各位，策略和信号两个库已经公开。现在准备服务器对接和小规模联调，想请交易同事先帮我们看一轮执行假设，尤其是下面这些：

1. 现货和永续两腿的实际手续费、返佣及折扣，分别按A/B账户给。
2. 不同币、不同单笔金额下，正常和极端行情的价差、滑点、能吃到的盘口深度；一次能下多少，退出时能下多少。
3. 我们现在小时参与率上限3%、仓位不超过2.5% OI和过去24h成交额5%。这是研究上限，想听实际执行是否偏大，尤其是小币和退出阶段。
4. 两腿成交间隔、部分成交和补腿通常多久；行情突然变差时可能拖多久、损失多少。
5. A/B之间资金调拨的实际通道、费用、到账时间；普通子账户和独立主账户分别是什么情况。
6. 保证金应该留多少现金缓冲；生息资产的折扣、额度和赎回时间，是否会影响补保证金、回购和还币。
7. 借币成本、可使用期限和提前收回时能给多久；原币理财能做哪些、赎回有什么限制。

目前自己的交易对后续资金费影响还没有标定，k=4仍是研究假设，压力测试保留0/1/2/4/6/8。新盘口检验里永续成本候选改善、现货候选失败，所以没有整套换成更低成本。最近30天原基线13.19%、只改有支持的永续成本后17.35%，都还是带尾仓的历史盯市年化。

请尽量按“币种＋订单金额＋账户模式/VIP＋正常值＋极端值＋经验/真实成交/盘口证据”反馈。暂时按经验判断也可以，我们会单独标出来，后面再用真实回执校准，不把经验数直接当实测参数。
