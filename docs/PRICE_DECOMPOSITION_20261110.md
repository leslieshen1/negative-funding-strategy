结论：**在冻结RC2的10/09～11/08连续经营月报中，基差参考损益为正，主要扣减来自平方根模型滑点/冲击。**这说明模型账目中的拖累在哪里，不等于已观测到真实订单冲击。全程未改模型、仓位、阈值或交易路径。

主口径固定：2026-10-09 00UTC至11-08 00UTC（北京时间两端均08:00），同一继承持仓状态、1000万U收益分母、720h，账面净收益108,427.31U、年化13.191989%。报告末仍有14币，未发生的未来退出费用不在月报内。

两腿细分：价差中现货5,759.96U、永续1,711.60U；平方根项中现货65,225.42U、永续63,862.19U。本窗口7012次双腿模拟切片，总两腿成交额约3082.17万U，对应平均模型价差2.42bp、平方根项41.88bp；这是成交额加权描述，不是额外费用。

平方根相对偏离为 `a = sqrt_y × Y_coin,time × sigma_time × sqrt(Q / paired_ADV)`；冻结代码令两腿`sls=slf=a`。这不是实盘两腿冲击相同的证据，需各自盘口和成交规模验证。

## 若要列四项，滑点只能是一个明确标注的代理

没有真实订单决策时刻、成交时刻和当时盘口，无法识别真实订单延迟滑点与因果冲击。模型也没有独立的延迟滑点参数，不能把129,087.61U再硬拆成“真实滑点”和“真实冲击”。

可以做一个不改变原收益的记账重基准：把成交参考从本小时VWAP换成上一完整小时最后可用收盘。两者之间的两腿基差变化列作**执行时段基差漂移代理**：

| 四项记账分解 | 金额U | 识别级别 |
|---|---:|---|
| 上一小时决策参考价口径的基差损益 | **+68,533.24** | 固定交易路径的记账参考，不保证该价格可成交 |
| 执行时段基差漂移（滑点代理） | **-18,458.66** | 上一小时收盘→本小时VWAP；并非实际订单延迟滑点 |
| 买卖价差 | **-7,471.55** | 冻结half-spread模型 |
| 规模相关模型滑点/冲击项 | **-129,087.61** | 平方根假设，不是独立实测的永久冲击 |
| 合计 | **-86,484.59** | 完全闭合 |

前两行相加就是上一表的50,074.58U。不能同时把50,074.58U与18,458.66U再扣一次；也不能把两套不同基准的“基差”混用。该小时代理还含两腿VWAP时点不一致等误差，不足以替代高频回执。

## 哪些结论还缺证据

| 项目 | 当前能做 / 缺失 |
|---|---|
| 基差、half-spread、平方根模型项 | 同一成交路径逐笔核算，六组原回放结果一致 |
| 独立真实订单滑点 | 未实测；缺订单决策/提交/成交时间及当时双腿盘口 |
| 自身交易的永久价格冲击、后续资金费影响 | 未因果识别；公开历史价格不能识别“没有我们交易会怎样” |
| 完整退出收益 | 原月报14币未结清，未来退出成本仍须单列 |

优先验证模型平方根项在不同腿、方向、规模桶和时段的误差；并对k=4做区间敏感性和未来真实执行校准。不要为提高同一历史月收益而直接下调成本、剔除亏损币或重训。

## 方法与复跑

观察器只向冻结引擎的独立副本添加计数/快照/交易trace，不回写任何决策变量。六组控制回放中，逐小时净损益、损益分项、持仓、双账户和完整episode数组均与未改引擎一致；每币基差恒等式、价差加冲击、独立交易向量重算、独立资金费与k扣减均闭合至1e-6U。

原始执行量、逐币持仓和容量明细留在授权本地目录，不进公开Git。公开部分为[组合结果](../mock/evidence/price-decomposition/RESULTS.json)、[汇总CSV](../mock/evidence/price-decomposition/SUMMARY.csv)、[验证](../mock/evidence/price-decomposition/VALIDATION.json)和观察器源码。

```sh
python -B mock/decompose_pair_price.py \
 --data /path/to/hash-matched-market-data \
 --inventory /path/to/private/inventory_caps.csv \
 --output /tmp/nfb-price-decomposition-new
```

可加`--case late_continuous_open`仅核对主窗口。需要原研究依赖及授权外部资产，缺失或哈希不符就停止；输出含私有trade trace，不要整体提交Git。策略、信号、模型、阈值及生产许可未变。
