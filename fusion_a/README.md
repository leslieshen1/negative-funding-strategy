# 通用资金规模 A 融合配置器 · dry-run

这是研究集成候选，不是 RC2 的替代，也不是已验收实盘。冻结基线仍是 `6b98320bfb707c903212e26888cef79a1c12342f` 上的 `nfb.strategy.20261108.rc2`，`CURRENT_RELEASE.json` 的 `submission_allowed` 保持 `false`。本包不读取交易接口，不提交订单、借币、撤单或划转。

策略标识：`nfb.fusion-a.research.20261123`。协议消息使用 `nfb.fusion-a.*.v1`。允许的模式只有 `dry_run` 和 `research_replay`，两者都强制 `submission_allowed=false`。

对方发送 position / universe 快照和执行回执。本包按快照输出绝对 target。Target 不是成交。账本只在回执能够放进已有资金批时更新；对不上的回执进隔离区，不会把持仓改成已平仓。

## 和 RC2 的关系

| 项目 | RC2 冻结基线 | 本包 |
|---|---|---|
| 身份 | `nfb.strategy.20261108.rc2` | `nfb.fusion-a.research.20261123` |
| 负费率门槛 | 8h 等值严格低于 −0.001，基差不高于 −0.003 | 只读 `CURRENT_RELEASE.json`，不调用 RC2 引擎 |
| 负费率新仓 | RC2 决策 | 默认必须带 RC2 决策，且数量只取更小值 |

没有 RC2 决策时，负费率只在显式标注的合成状态测试里按冻结门槛试算小预算。这不表示 RC2 已经允许该仓位。

## 资本身份

`A` 是规模参数，不是已到账现金。配置必须显式选择一种身份；两种公式不会自动互换。

- `GROSS_AUM_INCLUDING_BORROW`：`U=f*A`，`V=A-U`，`G=A`。只有声明现金没有额外负债时，净经济资本才等于 `U`。
- `NET_ECONOMIC_CAPITAL`：仅当 `f` 被确认为总资产里的 USDT 权重、且其余资产是匹配借币时，`U=A`，`G=A/f`，`V=G-U`。

`P&L/G` 和 `P&L/U` 不是同一个收益率。本包不输出年化收益。

## 资金不重复

每一批现金只有一个账户、一个用途。B 的可部署现金只来自 B 的闲置现金，并先扣安全留存、现金地板、在途、挂单预留和已缴保证金。A 的卖币回款记在 `BUYBACK_RESERVE`，默认不能转给 B，更不能充当 B 保证金。无息借币的利息保持为 0；借款本金不是利润。

正费率在 1 倍初始保证金下占用现货现金加永续保证金。负费率只占用配置的小预算保证金，现货来自借入原币。理财申购、待赎回和赎回在途都不是保证金现金。理财 APR 缺失时不做申购，也不填一个利率。

费用、冲击和完成率必须由输入给出。缺失时输出 `UNVERIFIED_NO_NEW` 或 `BREAKEVEN_ONLY`，不新增风险，也不填默认 bps。队列不建模。`ignored_forecast_rate` 会被忽略，避免未来费率进入 target。

## 状态

- 过期、冻结、断序、账实不符、缺少标定、熔断：停止新增。账本持仓保持不动。
- `STOP_NEW` 把绝对目标保持在账本事实。`REDUCE_TOWARD_HEDGE` 和 `REDUCE_TO_FLAT_TARGET` 只改目标，不改账本。
- 账实不符时强制保持账本数量，避免一份更平的快照被当成已经平仓。
- 撤单未确认继续占用预留。撤单确认后才释放未成交部分。
- 回执按 `stream_id` 和 `sequence` 排列。乱序先挂起，重复回执不重复入账，对不上的回执隔离。
- 资金费只按当时已有永续数量计入。结算窗口晚于回执时间的记录被拒绝。
- 外部申赎记入外部现金流，不记入策略盈亏。仍有负债、持仓、挂单、在途或未结理财时，年化完成为 null。
