# 策略规则与研究候选

版本：2026-11-07。统一口径为 Binance USDT 现货与线性 USDT 永续；不把其他交易所的借币、费用或账户体系混入此结果。

## 1. 经济结构及计量

A 提供已约定数量的原币，卖出现货；B 初始持有 1,000 万 USDT，做多同币同量的永续。退出时，B 平多仓，A 买回原币并偿还。借币成本按零计算；库存表的 30% 折扣已包含在数量中，不能再乘 30%。历史库存可用性按用户给定的静态假设，不声称取得历史可借记录。

所有收益除以固定初始 1,000 万 U。A 的借入原币并非免费权益，卖币收到的 USDT 对应原币债务；不能把卖币款计为收益或无负债本金。两账户允许互转，但不能凭空增加外部资金。

状态包含：空仓、持有、退出锁定、退出完成。退出完成须同时满足永续为零、现货已回购、原币债务为零；仍有任何义务时，`ann_completed_pct=null`。

## 2. 首笔入场与加仓

1. 最新已结算原始资金费率为 f，该次结算间隔为 h 小时，计算 r8=f×8/h。严格要求 r8<−0.001，恰好等于门槛不通过。
2. 上一已完成小时的贴水 b=(F−S)/S≤−0.003。
3. 原 v1 的预期收入门槛：历史预计资金费加基差变化收入，至少覆盖完整模型开平仓成本的 2 倍；不足或缺估计时不入场。
4. 库存、滚动成交额、OI、单币和组合额度均有剩余，且无退出锁、公告退出或既有风险禁入状态。
5. 原 v1 的公开数据 ADL 风险代理过滤保留：小时价格上涨超过 10%，同时原币计 OI 下降，延迟 2 小时起禁入 24 小时。它不是交易所真实 ADL 排名，也不能保证不会被 ADL。

第一部分主参考和优先候选沿用 v1：条件通过即可开始按预算建仓，不强制首笔等待 T−1h。这是独立研究建议，不把旧对话里的 T−1h 静默写成另一条规则。首笔 T−1h 作为独立实验比较；该实验只限制空仓后的首笔，加仓无需再等，且包括 1h、4h、8h 合约。

1h 原始结算费率须低于 −0.0125%，4h 低于 −0.05%，8h 低于 −0.1%。这只是比较信号的单位换算；资金费现金流按每次实际原始费率与实际持仓计量，不能把每次都按 8 小时现金收入相加。

持有时可在任何满足条件的决策小时加仓。加仓判断还保留原 v1 对自身仓位影响后的负费率判断；不限制“一轮只能加一次”。入场条件失效只停止加仓。容量下降、保证金不足、交割公告等风控减仓独立于信号失效，不应混为同一退出规则。

## 3. 退出

最近 24 小时市场已结算原始费率合计转正（严格 >0）即锁定退出；包含建仓前的结算记录。退出信号不使用自身影响模型修正后的费率。数据或价格暂缺时保留退出锁，恢复可成交后继续，不因信号反转重新加仓。

退出执行受同一参与率预算约束；不允许一面按预算开仓，一面假设任何时候都能一次性平掉。公告驱动的交割、下架和换币事件只在公告可用之后触发；未在交割前完成则报错，不能填造成交或偿还。

为了评估本次窗口，结束前 24h 开始收尾，后续 216h 只退出。这是回测终点处理，不是实盘每日清仓规则。

## 5. 账户及单位

库存与现货都用原币数量 q；永续下单数量=q/每合约数量单位对应原币数。1000 系合约不能直接拿现货数量发给永续。两边共同数量步长应取换成原币后的精确最小公倍数，不能直接取较大的步长；历史模拟仍用连续数量，当前步长审计没有冒充历史交易过滤器。

A 净权益=A 现金−尚欠原币的现货价值；B 净权益=B 钱包+永续浮盈亏。两者合计减初始 1,000 万应等于策略联合损益，原库存本身涨跌不属于策略收益。

USDT 单资产、线性永续、配置 1x 时，B 应保留至少 Σ(q×永续平均开仓价) 的钱包资金。A→B 补保证金从 A 已有现金取；B→A 只能用已实现、可释放且不影响保证金的余额。不能把 B 未实现浮盈提前当成 A 可花的 USDT。

参考模拟允许即时免费内部到账，并另外做 1/4/8 小时到账延迟诊断。诊断沿固定成交路径推迟到账，缺口表示需要预拨资金、缓冲或改变成交，不能把这条不可行路径当成另一个真实收益结果。

## 6. 与执行侧的边界

本阶段交付参数、状态语义、可复核结果及约束定义。后续 JSON 协议需明确输入时间、最新结算原始费率与间隔、实时公告日程、实际双边盘口/可成交量、原币库存、两账户可用余额及保证金、订单/成交/资金费/转账回执。

输出应表达目标原币数量、允许新增量、退出锁及原因、容量与保证金约束、待偿还原币和数据版本；执行侧回报实际成交，策略侧据此更新状态。此处没有下单模块，参数 JSON 也不能直接发送为生产订单。旧 JSON 包仍是旧版本，不能将其 −0.05% 配置误认为已同步本候选。
