# 数据、模型及结论边界

研究使用真实历史市场数据与明确模型假设。数据真实并不意味着反事实成交和收益已经真实发生。

## 已验证的部分

冻结原 v1 在独立取得的输入上可重复运行；−0.1% 门槛结果为 75.16414173387383%。扩展引擎关闭新选项后逐项数值等价。过去信息波动率、结算事件含零费率、下单预算使用过去小时、实际当小时成交量只约束成交、独立账户和退出锁有边界回归检查。

新增数据来自 [Binance Public Data](https://github.com/binance/binance-public-data/)，已保存的压缩档案逐个核对官方 CHECKSUM。官方说明现货 2025 年起时间戳为微秒，导入代码显式转换，避免与永续毫秒混淆。

## 尚未由数据证明的部分

| 缺口 | 本次处理 | 影响 |
|---|---|---|
| 完整连续历史 L2、队列和双腿到达路径 | 成交额深度代理、历史永续 aggTrades 系数、分钟抽查 | 不能证明可得小时 VWAP 或原子双腿成交 |
| 自身多仓对费率的因果影响 | k=4 基准，k=6 与成本翻倍压力 | 年化高度敏感；k 不是由公开市场相关性识别出的因果参数 |
| 历史信息实际接收时间 | 交易所事件时刻与公告发布时间，保守小时对齐 | 并非亚秒无延迟回放；事件抖动及停机接收仍有不确定性 |
| 历史下一次结算公告日程 | T−1h 实验延续最近已知结算间隔 | 间隔临时改变时会判断错时点；没有排除 1h 合约 |
| 每币历史现货价差 | 老数据标量先验；新增币 5bp 半价差先验，永续实际样本动态缩放 | 严格信息时间修正未消除所有静态先验偏差 |
| 历史逐币保证金阶梯、账户权限、ADL | 1x 初始保证金及小时标记价格代理 | 不是完整强平、保证金档位或交易所故障回放 |
| 历史交易步长、最小金额及最大订单量 | 审计当前规格；历史用连续数量 | 不能证明所有小尾仓当时可按最小步长成交 |
| 历史库存及币种身份 | 用户静态库存和提供的映射；价格比例作合理性检查 | 不能证明换币前后原币债务等价，也未消除库存选择偏差 |
| 未观察样本外期 | 两个时间段及逐月拆分，周块重采样 | 原有 HO 已被观察；不能称为新的独立样本外检验 |

大部分历史资金费结算名义价格采用该小时的 mark open 代理，11 月 API 有精确返回时才替换；不是每条都取得交易所收费回执。资金费率来自真实结算，但加入自身费率影响后的现金流属于模型。

预期收入表按月用此前 90 天、已经完成的最长 168h 结果更新，每格至少 200 个币小时观察。原模型训练标签使用 24h 连续退出确认，而实际退出确认只有 1h；单独测试了对齐版本。币小时大量重叠，不等于 200 次独立交易；尚未采用按完整费率轮次聚类的不确定性门槛。

成本压力的“翻倍”仅指价差与冲击系数翻倍，手续费没有翻倍；门槛训练表不随该执行压力重新标定，因此它是固定信号下的压力诊断，不是假称完整重新估计的策略。

Binance 的[保证金说明](https://www.binance.com/en/support/faq/detail/360033162192)明确区分初始与维持保证金，并允许部分档位调整不提前公告。本次未以当前档位回填全年。现货 VIP3 taker 0.06% 可从[官方费率页](https://www.binance.com/en/fee/trading)核查；永续 0.032% 延续指定收费假设，未验证用户两个实际账户的专属历史佣金。

## 生命周期

补充历史档案目录避免仅按当前可交易列表筛选，并补入年度内 21 个配对品种。四份官方公告覆盖 8 个新增品种的交割、下架或迁移；详见 `research/lifecycle_events.json`。例如 [STG 合并公告](https://www.binance.com/en/support/announcement/detail/0c1e8975f48d42c4b856c113926c5fdd)规定永续结算和现货停止时间不同，STG 原币债务不能凭模型直接用 ZRO 偿还。

公告当前页面存在后续编辑，历史原文快照与真实接收时间未齐全。因此公告过滤提高了模型完整性，仍不是严格历史信息流的证据。

## 如何使用结果

优先候选在相同数据上实现更小单币暴露、全部模拟退出，并在所列成本压力下保持盈利，足以作为后续影子验证的研究版本。它不是实盘预期收益或已经可执行的证明。应从实际回执估计成交不足、两腿延迟、费率衰减、保证金需求与退出时间，再冻结新的参数版本；不能为追求回测年化反复调低冲击参数。
