# RC2 执行方联调验收

先校验 SHA256 文件清单和 MODEL_PROFILE，禁止把旧策略ID、旧参数或旧样例带入本次测试。内网可采用已有消息队列、目录或RPC，协议不绑定传输方式。

本地72项检查包括42项合同检查和30项模型／决策检查；另有38个合同消息与9组生成式运行样例。它们只证明本地检查结果。下面“执行方验收”均需现有引擎实际运行并返回状态／日志，当前尚未收到该证据。

## 1. 单次输入输出

| 用例 | 执行系统应表现出的行为 |
|---|---|
| 01_enter／02_add | 按新profile、双腿方向、原币／1000合约单位和许可差量处理；新增不再等T−1h |
| 13_equal_threshold_hold／14_below_threshold | −0.1%恰好相等不能新增；严格更负才可通过相应门槛 |
| 15_one_hour／16_four_hour | 使用原始费率与实际间隔，不排除1h／4h合约 |
| 03_hold／20_pause_new／22_adl_pause | 不额外生成订单，不把停止加仓自动当作清仓 |
| 04_reduce／05_exit／17_partial_exit | 按本次许可量执行，减仓／退出与开仓共享小时预算；最终目标0不等于本次全部平掉 |
| 10_missing_quote_exit_locked | 无报价不成交，退出锁与最终零目标保留 |
| 19_transfer_wait | 可以处理划转意图，但到账前不得把这笔钱投入回购或保证金 |
| 21_borrow_recall | 已收到的召回事件锁退；不得等待费率重新触发 |
| 07_partial／08_reconcile | 实际两腿数量分开记；部分成交后进入敞口核对，不当成完整对冲 |
| 09_transfer_pending | PENDING不改变已到账余额，SETTLED必须有实际到账时刻 |
| 11_actual_funding | 按真实资金费增量记账，不再加减研究k模型的现金影响 |
| 12_coin_return | 区分A恢复原币与提供方确认归还，保留未清义务 |

所有价格、数量、余额和费率均为合成数据，不用于生产。收到许可后仍应遵守真实交易所过滤器、价格界限和账户限制。

## 2. 必须用执行引擎补做的持久化／并发验收

| 编号 | 场景 | 验收要求 |
|---|---|---|
| E01 | 同request_id、相同内容重复发送 | 返回原决策／原处理结果，订单与预留不重复增加 |
| E02 | 同request_id、不同内容 | 明确拒绝，不覆盖原记录 |
| E03 | 同decision_id重放，包括重启后 | 已消费数量不能再次消费；持久化防重 |
| E04 | 两请求争用同一账本版本／同一剩余额度 | 原子检查版本并预留，最多一个成功；组合、单币和小时预算均不超用 |
| E05 | 两币各自满足限制、合计超过组合／B可用资金 | 共享预算统一分配，不能分别满额执行 |
| E06 | 已提交子单未成交、撤单未确认 | 保留额度占用；收到撤单确认后才释放未成交预留 |
| E07 | 许可过期但已有在途订单 | 不新增订单；执行撤单流程；实际迟到成交仍记账，不能按过期丢弃 |
| E08 | 同成交／资金费／归还回执重复，包括跨消息重放 | 事件唯一键持久化；余额、持仓、费用与原币义务只记一次 |
| E09 | 回执乱序／断线恢复 | 按实际事件及版本核对；不能让迟到快照覆盖较新实际持仓 |
| E10 | 部分成交后资金费结算 | 资金费按交易所实际持仓、实际金额入账；残余敞口保持可见 |
| E11 | A资金不足、B有浮盈但可划转额不足 | 不把浮盈当A现金；明确等待、可划转额度和到账状态 |
| E12 | ADL／强平／退市／交易中断／原币收回 | 保留实际回执与风险锁，停止新增，核对残余腿及偿还义务 |
| E13 | 最低金额导致尾仓不能正常成交 | 不回填全部完成；返回残余数量与需处理原因 |
| E14 | 行情／账户变旧或价格突破许可界限 | 拒绝继续消费旧许可，请求新状态；不得擅自放宽价格和费用预算 |

离线校验器不提供这些生产持久化／并发能力。规则定义与执行侧实现均需留证，不能用本地单报文PASS替代E01—E14。

## 3. 交回材料

填写 `执行方验收回执模板.json`，提供执行引擎版本、包哈希、用例编号、实际状态差异及日志引用。真实密钥不放入回执。全部输入输出保持原币／合约单位，事件时间和实际接收时间分开。

验收期间仍使用联调／影子模式。收到真实回执后，策略方再开展3.8对账与3.9成本容量校准；本包不授权真实下单、借币或划转。

## RC2模型接入补充

执行侧还需核对模型快照哈希、实际发布时间、有效月份、26条历史窗口以及历史重放模式。缺模型／缺历史停止新增，不能撤销退出锁；模型过期不能沿用旧月份。已有资金修复意图不代表1x保证金已恢复。成本校准只到2026年9月30日，当前必须保留旧样本提醒。
